Hoka Rocket X 3 vs On Cloudboom Echo 3

To konkurransesko som ofte vurderes mot hverandre. Pris, vekt, demping og pris per kilometer side om side.

Kort fortalt

  • On Cloudboom Echo 3 er billigst, fra 1 919 kr mot 1 999 kr.
  • Per kilometer er Hoka Rocket X 3 billigst: 6,66 kr mot 7,11 kr, regnet med 300 og 270 km levetid.
